MRG tube label analyzer.

This program takes in at least one image/video file(s) of the label(s) and turns then data into a customizable .CSV file.


---
## Dependencies:
- Java
- Python
- Ollama


## Setup:
1. Install python from the Microsoft Store: [https://apps.microsoft.com/detail/9nq7512cxl7t?hl=en-US&gl=US](https://apps.microsoft.com/detail/9nq7512cxl7t?hl=en-US&gl=US)
2. Install dependencies by running `install_dependencies.bat`

---
## Usage:
### Basic usage:
1. Run `main.java`
2. Import an image
3. Export the .CSV file
4. Click the `Show .CSV` button to see the .CSV file

### Customization:
Drag the column headers in order to change the order and customize how the .CSV file will look
